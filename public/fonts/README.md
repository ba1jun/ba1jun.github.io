# Chinese name font

`juniverse-name-serif-medium.woff2` is a local subset of Adobe's
[Source Han Serif SC Medium](https://github.com/adobe-fonts/source-han-serif/blob/release/OTF/SimplifiedChinese/SourceHanSerifSC-Medium.otf),
version 2.003. It contains only 白 (U+767D) and 骏 (U+9A8F), at weight 500.

The subset is 2,220 bytes. It was generated with FontTools 4.55.4 and Brotli,
with layout features removed and copyright and license metadata retained.
The modified font's family and PostScript names were changed to
`Juniverse Name Serif` and `JuniverseNameSerif-Medium`; the original license
and copyright notice are provided in [OFL.txt](./OFL.txt).

The source OTF's SHA-256 is
`1d4dc4b757c07034e2412d6edf48f54f94ec7172d4deb3b90a3e4fc9dcb94f5d`.

The homepage imports `src/styles/chinese-name.css`; research pages show only the English name.
Regenerate the subset and update its CSS `unicode-range` if the name changes.
